# cutline

Champions League 2026-27, simulated 10,000 times after every matchday.

Work in progress. Every prediction is committed to [`predictions/2027/`](predictions/2027/) before the
next matchday kicks off; the commit time is the record. The first snapshot (before Matchday 2) uses
untuned default hyperparameters and says so in its `notes`.

Data: match results and fixtures from UEFA's public match data and
[football-data.co.uk](https://www.football-data.co.uk/).
